# 心芽 🌱

> 私有记录 + 可控分享，属于你的内心花园

心芽是一款面向个人的私有化心得记录应用，通过四页面架构（萌芽 / 枝叶 / 年轮 / 根系）帮助你记录、回顾和成长。

## 功能特性

- **心得记录**：富文本编辑，支持代码块、列表、字体颜色等格式
- **标签管理**：两级父子标签，灵活组织思绪
- **间隔复习（拾遗）**：AI 自动生成复习题目，基于遗忘曲线安排复习
- **AI 月度洞察**：月末自动总结成长轨迹
- **截图分享**：一键生成精美分享图，支持链接分享
- **双主题**：春日萌芽（浅色）+ 墨色幽微（暗色）
- **数据导出**：Markdown 格式一键导出全部心得

## 技术栈

- **框架**：Next.js 16 (App Router) + React 19 + TypeScript 5
- **样式**：Tailwind CSS v4 + CSS 变量主题
- **数据库**：PostgreSQL 13 + Prisma 6
- **AI**：DeepSeek API（题目生成、月度洞察）
- **部署**：PM2 进程管理，阿里云 ECS

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器（需先开启 SSH 隧道连接数据库）
npm run dev
```

## 部署

```bash
# 服务器端部署
git pull gitee main
npm run build
pm2 reload xinya
```
