## 二、新 Mac 环境安装

**不需要安装的软件**：❌ Python、❌ PostgreSQL（数据库在服务器上，通过 SSH 隧道连接）、❌ VS Code（Qoder 内置编辑器可替代）。

**B1. 安装 Homebrew**（macOS 包管理器）
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
brew --version
```

**B2. 安装 nvm（使用国内镜像）**
```bash
export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node
curl -o- https://gitee.com/mirrors/nvm/raw/master/install.sh | bash
# 重启终端后验证
nvm --version
```

**B3. 安装 Node.js**（版本与服务器一致，以第一步查到的为准）
```bash
nvm install <服务器版本号>
nvm use <服务器版本号>
nvm alias default <服务器版本号>
node -v
```

**B4. 安装 Git**
```bash
brew install git
git --version
```

**B5. 安装 Qoder**，登录原账号。

**B6. 配置 SSH Key**（⭐ 唯一推送方式，不再使用 PAT/HTTPS，旧令牌已于 2026-07-29 全部删除）
```bash
# 生成 SSH Key（ed25519 算法）
ssh-keygen -t ed25519 -C "你的邮箱" -f ~/.ssh/id_ed25519

# 复制公钥（直接进剪贴板）
pbcopy < ~/.ssh/id_ed25519.pub
```
将公钥登记到三个平台：
1. GitHub: Settings → SSH and GPG keys → New SSH key
2. Gitee: 设置 → SSH公钥 → 添加公钥
3. 服务器: `ssh-copy-id -i ~/.ssh/id_ed25519.pub admin@47.100.106.213`

验证：
```bash
ssh -T git@github.com
ssh -T git@gitee.com
ssh admin@47.100.106.213
```

## 四、环境配置

**D1. Git 用户信息：**
```bash
git config --global user.name "kangkang919"
git config --global user.email "你的邮箱"
```

**D2. 创建 .env**（从旧电脑拷贝，或 `cp .env.example .env` 后填写）：
- `DATABASE_URL`：`"postgresql://xinya:<密码>@localhost:5432/xinya_db"`（⭐ 走 SSH 隧道，所以是 localhost）
- `JWT_SECRET`：与服务器一致（64 位随机字符）
- `SMTP_USER`：1243177461@qq.com
- `SMTP_PASS`：QQ 邮箱 SMTP 授权码
- `NEXT_PUBLIC_BASE_URL`：http://localhost:3000
- `DEEPSEEK_API_KEY`：AI 功能密钥

**D3. SSH 隧道（数据库连接的前提，必须）**

服务器 PostgreSQL 只允许本机连接，本地开发必须先开隧道，**不能直连服务器 5432 端口**：
```bash
ssh -L 5432:localhost:5432 admin@47.100.106.213
```
每次 `npm run dev` 前先在独立终端开启此隧道并保持不关。
可选自动化：`brew install autossh` 实现断线重连。

## 六、日常部署流程

1. 本地提交并双推：
```bash
git add -A
git commit -m "提交信息"
git push origin main
git push gitee main
```

2. SSH 登录服务器部署：
```bash
ssh admin@47.100.106.213
cd /www/wwwroot/xinya
git fetch gitee
git reset --hard gitee/main
rm -rf .next
npm run build
pm2 delete xinya
pm2 start ecosystem.config.js
pm2 save
exit
```

3. 浏览器访问 https://shuxiangnote.top 验证。

> 部署详细规范（prisma migrate deploy、清理 .next 的原因等）以《新芽dev-framework.md》Phase 7 为准。
